API

接入

Base URL{{ base_url }}
Auth{% if token_on %}X-Gofer-Token / Bearer{% else %}—{% endif %}
通知POST /v1/notify
锁票POST /v1/lock
查询GET /v1/requests/:id

请求是异步的：返回 202 + request_id，结果通过请求状态查询或面板查看。

CLI

命令行

gofer notify --channel wechat -m "放票了"
gofer notify --channel xhs --group "群名" -m "放票了"
gofer lock --cinema-id 37534 --movie-id 1545360 \
  --show-date 2026-11-12 --num-seats 2
gofer requests --limit 20

设置 GOFER_URL / GOFER_TOKEN 后，CLI 可直接调用远端 Gofer。
